3. 功能敘述（摘要）

業務人員可於線上網頁中，依引導式步驟填寫營業（商）用車險基本資料，完成試算與投保（預查、車輛、被保險人、要保人、KYC 等六階段）。羅賓斯保代透過新安東京 API 將資料傳遞給新安東京，由其進行資料檢核、保費計算與核保；羅賓斯保代系統依審核結果取得對應保單文件（PDF）供業務人員儲存與下載。

4. 使用者角色

範圍界定：本次功能僅涵蓋「業務人員」單一角色；不含保戶端、審核人員端之操作介面。

5. 業務需求（Why）

5.1 背景 / 痛點

商用車險（計程車、租賃小客車、營小客等）試算與投保作業，目前仰賴人工登入保險公司系統或紙本作業，流程分散且步驟繁瑣。

車輛資料（行照、駕照）需人工逐項輸入，容易發生輸入錯誤與資料不一致。

業務人員無法在同一介面完成「試算 → 核保 → 取得文件」的完整流程，作業往返耗時、體驗不佳。

核保結果與所需文件（要保書、繳費單、報價單）散落各處，缺乏統一取得與保存的管道。

本節以定性方式描述。

5.2 目標 / 成功指標

6.1 險種選擇（階段 1）

功能描述

業務人員上傳行照與駕照，透過 OCR 自動辨識，取得駕照號碼(身分證)和牌照號碼，代入羅賓斯科技的廠代碼工具，獲得強制險生效日、任意險生效日。此外，進行投保險種的填寫。

需求

上傳行照、駕照圖檔（必填），並提供「證件對照」預覽。

駕照資料可指定作為被保險人資料。提供「OCR 辨識駕照」功能，取得「駕照號碼（身分證）」、「性別」、「姓名」、「出生日期」、「住址」。

提供「OCR 辨識行照」功能，取得「牌照號碼」、「原發照日期」、「載運人數」。

將「牌照號碼」+ 「車主身分證號碼」代入羅賓斯科技的廠代碼工具查詢，取得「廠牌車型代號（8 碼）」、「強制險到期日」、「任意險到期日」、「廠牌」、「車系」、「車型(車款)」、「出廠年月」、「排氣量／馬力」、「重置價格」、「引擎號碼」、「車身號碼」。

險種選擇（可複選）：強制險、任意險；擇一或同時勾選。

勾選險種後開放對應之「生效日」，並依生效日自動代入「到期日」（生效日 + 1 年），到期日為唯讀。

預查通過後方可點擊「下一步」；未通過則「下一步」維持停用。

圖檔以 BASE64 格式傳送至 API（DrivingLicenseImage / VehiclelicenseImage）。

OCR 回應時間門檻 < 5 秒，見 8.1。

險種資料欄位

情境 / 結果

規格 / 限制

牌照號碼分為「車牌前」「車牌後」兩個輸入框，送 API 前組合為 TagID。

到期日由系統自動計算並代入，使用者不可手動修改。

續保情境範例：前一份保單到期日為 2026/07/15，新保單生效日即為 2026/07/15；若 (2026/07/15 − 今日) > 60 天，則不允許進行試算／投保。
